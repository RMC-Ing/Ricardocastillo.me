- SEO básico: títulos, metadescripciones, canonical, Open Graph y datos estructurados.

## Para publicar
1. Subir todo el contenido de esta carpeta a la raíz del hosting.
2. El archivo principal debe quedar como `/index.html`.
3. Mantener intactas las carpetas `/assets` y `/proyectos`.
4. Conectar el dominio `ricardocastillo.me` mediante DNS.
5. Después verificar el dominio en Google Search Console y enviar `/sitemap.xml`.

No es necesario contratar WordPress para publicar este sitio estático.
